# 調査：Jev と System One（速い判断のモデル）（2026-10-03）

開発者さんから「Jevの発想が使えるのでは」と言われて調べたもの。ウェブで読んだ内容の要約で、**自分で動かして確かめたものはまだない**。数字はすべて各プロジェクト・論文の自己申告。

## Jev とは
- TypeSafe AI（元OpenAIの研究者が設立）のモデル。2026年9月に誰でも使えるようになった
- 文章を生成しない。状態（テキスト）と型つきの質問を渡すと、確率と確信度つきの答えを返す。質問の型は次の3つ
  - Choice：選択肢から1つ選ぶ（最大255）
  - Score：段階で採点する
  - Noul：はい・いいえの確率
- 0.07〜0.5秒。入力100万トークンあたり0.042ドル、出力は無料。登録時に5ドルの無料枠。重みは非公開
- 開発元は「速い直感（System 1）」の役と位置づけている。「単独のエージェントには向かない。LLMと組み合わせて、ループの中の繰り返しの判断を任せる」

## 研究（いずれも2026年9月の arXiv）
- [Jev-Mem](https://arxiv.org/abs/2609.23986)：エージェントの記憶の操作を速い判断側に任せる。任せる操作は、記憶の分類・つなぎ方・どの検索を使うか・どれだけ探すか・候補の採点・いつ探すのをやめるか。LLMは答えを組み立てるときだけ使う。長い会話の記憶のベンチマーク（LoCoMo）で、精度が上がり、記憶づくりが6.6倍速くなったと報告。コードは未公開
- [Jevの評価](https://arxiv.org/abs/2609.37647)
  - 一般的な分類は95〜99%と強い
  - **少数言語、細かい・ノイズの多いラベル、ルーブリックによる質の判断では落ちる**
  - Choiceの確率はよく較正されているが、はい・いいえは閾値の調整が要る
- [エージェントの安全判断での評価](https://arxiv.org/abs/2609.33401)
  - 平均の成績が良くても、特定の種類の攻撃を自信満々に見逃す
  - 「1%しか見逃さない」といった厳しい条件を課すと、自動で任せられる範囲はほぼなくなる
  - **安全の判断を速い判断モデルに任せるべきではない**
- [Jev in the Wild](https://arxiv.org/abs/2609.30216)：公開プロジェクト2,170件の使われ方の調査

## ソフィアへの示唆（推測）
1. **安全の層（`safety.py`）は、今の決定的な規則のままにする。** 速い判断モデルには任せない（安全判断の評価論文の結果より）
2. **使い道の候補**
   - 自分の時間に動くかどうか
   - どの投稿に反応するか
   - 記憶をどれだけ探すか（Jev-Mem）
   - 感情の評価
   - PC操作の一歩一歩（ブラウザ操作の例：[Jev Ultrafast](https://github.com/browser-use/jev-ultrafast)、[Sedum](https://github.com/sedum-dev/sedum)）
3. **継続学習とのつながり（一番大事）。** ソフィアは毎日、世界からの反応（`valence`：いいね・返信があったか）という正解ラベルを、タダで手に入れている。速い判断モデルに「この状況でこの行動をしたら反応が返るか」を毎晩学ばせれば、経験で直感が育つ。人間の、ドーパミンによる習慣の学習に近い
   - しゃべる頭（LLM）は固定のままでいい
   - 小さな判断の頭だけが育つ。小さな頭が苦手なのは会話で、判断なら得意。0.5Bの実験で分かった壁を避けられる
   - Laya・Kev は自分のラベルで追加学習でき、sokudan は日本語に強い。まずはこれらを土台に、手元で試すのが早い
4. 注意
   - 日本語で、しかも「投稿の良し悪し」のような質の判断は、評価論文が言う弱点そのものにあたる。期待しすぎない
   - 本番のVPSはメモリが小さいので、3億パラメータ級のモデルを常駐させられるかは要確認
