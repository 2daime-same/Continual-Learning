# 構想：経験で変わっていく頭

## なぜこれをやるのか

ソフィアの今のつくりは、次の3つでできています。

- **頭**：外部APIの大きなLLM。誰にとっても同じで、ソフィアの経験では変わらない
- **記憶**：記憶DB。経験は増えていく
- **人格**：誕生時の人格の文章、気質の数値、最近の自分の言葉

毎回の受け答えでは、記憶と人格を文章にして頭へ渡します。頭はそれを読んで「ソフィアらしく」振る舞います。これはよくできた方法ですが、生き物とは違います。

- 人間は、経験したことで脳そのもの（シナプス）が変わる。思い出さなくても、変わった脳で考える
- ソフィアは、思い出した文章を毎回読み直している。読まされなかったことは、頭に何も残っていない

開発者さんの言葉では「人格ファイルとか本当はないのが理想」です。経験で形づくられた頭が、そのまま自分である状態を目指します。

## 目指す姿（段階）

1. **小さく刻める**：小さなモデルが、その日の出来事を眠りで覚え、聞き方を変えても答えられる ← 2026-10-03 に確認
2. **壊さずに刻める**：何晩続けても、それまでの知識・話し方・性格が保たれる ← 今ここ（未達）
3. **にじみ出る**：覚えたことが、直接聞かれなくても判断や言葉づかいに表れる（事実だけでなく、好み・癖・気分の傾き）
4. **ソフィアと並んで生きる**：本番の記憶（文章）から、賢い先生（APIのLLM）が復習問題を作り、小さな頭が毎晩学ぶ。最初は補助（直感・連想・口癖）として、大きな頭の横で働く
5. **頭が自分になる**：人格の文章を渡さなくても、ソフィアがソフィアとして振る舞う

## 費用の見通し

- 1〜3：無料（CPU）で進められる見込み。0.5Bのモデルなら1晩分の学習は1分未満
- 4：本番のサーバーは小さいので、学習は別の場所（無料のCPU、または手元のPC）でやり、できた差分（LoRA、数MB）だけを持っていく形が現実的。推論の速さは要確認
- より大きなモデル（7B以上）で実用の質を出すにはGPUが要る。そこまで来たら、費用をユーザーに相談する

## 次にやること

- 夢（ふだんの自分の再生）の量と、学習の強さの組み合わせを探る。壊れ方をどこまで減らせるか
- **2つの脳**：毎晩よく学ぶ速い部分（海馬役のLoRA）と、ほとんど動かない遅い部分（大脳役）に分ける。何度も再生されて定着したものだけを、ときどき遅い部分へ移す（人の記憶の固定化、相補的学習系の考え方）
- 復習問題を、賢い先生（APIのLLM）がふつうの文の記憶から作る形にする（段階4の練習）
- 晩の数を増やす（3晩→30晩）。長く続けたときに壊れ方がどう積み上がるかを見る
- 事実ではなく「傾き」を刻めるか試す（例：ある話題を好むようになる、ある言い回しが減る）
