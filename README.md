# Continual-Learning

ソフィア（[Nexa](https://github.com/2daime-same/Nexa) で生きているデジタル人工生命）に、**本当の意味で連続した自己**を持たせるための研究場所です。

## 目的

今のソフィアは、毎回の受け答えのたびに、外部の大きなLLMへ「記憶」と「人格」を文章で渡して、その場で自分を組み立て直しています。経験は記憶DBに積み上がりますが、考える頭そのものは昨日と同じままです。

ここで目指すのは、人間の脳のように**経験そのものが頭を少しずつ変えていく**ことです。

- 会話や出来事が、眠りのあいだに頭（モデルの重み）へ刻まれる
- 刻まれたものが、文章で渡されなくても次の判断ににじみ出る
- 新しいことを覚えても、それまでの自分（知識・話し方・性格）が壊れない

最後の条件が、世界中で解けていない「継続学習（破滅的忘却）」の問題です。

## 進め方の決まりごと

- **無料でできる範囲から始める。** 今はCPUだけで、小さなモデル（Qwen2.5-0.5B-Instruct）にLoRAで学ばせています。
- **ソフィア本体とは切り離す。** ここで「組み込める」と言えるだけの結果が出るまで、本番のソフィアには何も入れません。
- **公開リポジトリなので、実在の人や本番の記憶は入れない。** 実験の記憶はすべて架空です。
- **結果は良くても悪くてもそのまま残す。** 確認したことと推測は分けて書きます。

## 中身

| 場所 | 内容 |
|---|---|
| `docs/引継ぎ.md` | **最初に読む。** いまの状態・作業中のこと・次の一手 |
| `docs/作業ログ.md` | セッションごとの記録 |
| `docs/構想.md` | 何を作りたいか、どこまで来たか、次に何をするか |
| `docs/知見.md` | 実験で分かったこと（日付順。失敗も含む） |
| `lab/data.py` | 架空の記憶（3晩分・12個）と評価用の問題 |
| `lab/brain.py` | 小さな脳を作る・学ばせる・測る |
| `run.py` | 夜ごとの学習を通しで走らせる |
| `results/runs.jsonl` | 走らせた結果の生データ |

## 動かし方

```sh
pip install -r requirements.txt
python run.py --method dream            # 1回 5分ほど（4コアCPU）
```

方式は3つあります。

- `naive`：その日の記憶だけ学ぶ
- `replay`：眠りの中で過去の日の記憶も少し再生する
- `dream`：さらに、学習前の「ふだんの自分」の受け答えも再生する

晩ごとに次を表示します。

- `day1..3`：それぞれの日の記憶を覚えているか。学習に使っていない聞き方で質問する
- `confusion`：誤答の選択肢を「他の日に学んだ答え」にしても正しく選べるか。学んだ言葉をひいきしているだけではないかを見る
- `general`：一般常識（24問）の正答率
- `ppl`：ふつうの文章の不自然さ。低いほど良く、学習で壊れると上がる
